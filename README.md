# Mi carta para Marian 💜

Sitio web romántico/divertido, modular y responsive.

## Archivos
- index.html: bienvenida y carta principal
- historia.html: línea de tiempo
- galeria.html: galería con filtros
- juego.html: mini juego de atrapar corazones
- bromitas.html: bromas internas
- atajos.html: Easter eggs
- contacto.html: cierre y firma
- style.css: estilos compartidos
- script.js: corazones, botón mágico y funciones compartidas
- assets/img: coloca aquí las fotos personales
- assets/audio: coloca aquí sonidos o música
- assets/fonts: coloca aquí fuentes locales si quieres

## Personalización rápida
1. Sustituye los textos de ejemplo por recuerdos reales.
2. Coloca tus imágenes en `assets/img`.
3. Para usar una foto como fondo de una tarjeta, puedes añadirla como `background-image` en `.photo`.
4. El récord del juego se guarda en `localStorage`.
5. No requiere servidor: abre `index.html` directamente en el navegador.

## Nota
Los textos marcados como ejemplos son intencionalmente genéricos para que puedas sustituirlos por bromas que solamente Marian entienda.
